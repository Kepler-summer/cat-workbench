全域导航与交互修复
优先级: 高

问题诊断

以三个角色视角协同排查全域交互断裂点：

问题 #1 — 产品经理视角
首页「糖果小铺」入口卡片 (home-points-card) 展示了"今日任务 doneTasks/total"统计，但整张卡片绑定 data-open="game"，点击后跳转到糖果小铺（游戏页），而非用户期望的「今日计划」页面。用户看到任务数据，自然期望点击进入任务列表。
修复方案：将卡片拆分为多个可点击区域：等级/糖币区域 → 进入糖果小铺 (game)；今日任务区域 → 进入今日计划 (todo)；藏品区域 → 进入藏品图鉴 (game + tab=collect)。每个统计指标 (hpc-stat) 独立绑定 data-open 目标。
问题 #2 — UI设计师视角
首页「今日概览」环形指标 (rings) 绑定了 data-open 跳转，但缺少视觉反馈（hover/active 状态不明显），用户不知道这些圆环可以点击。
修复方案：为 .ring 增加 cursor:pointer + hover 微动效（缩放 1.03 + 阴影增强），并在圆环下方增加小字"点击查看"提示。
问题 #3 — 游戏架构师视角
糖果小铺内部「每日任务」卡片 (daily-task-card) 的完成按钮直接执行 completeDailyTask()，但缺少任务完成后的视觉过渡动画（直接重渲染，体验生硬）。
修复方案：任务完成后增加 300ms 收束动画：卡片背景渐变为 .done 状态 + 糖币 +N 飘浮动画 + 微震动反馈（移动端 navigator.vibrate(10)），再触发重渲染。
问题 #4 — 全域排查
以下区域需全域检查是否存在同类交互断裂：
renderHome() 中所有 data-open 元素的跳转目标是否与用户预期一致
renderInsight() (洞察页) 中 data-open 跳转是否正常
wireHome() 中事件绑定是否覆盖所有动态渲染的元素
抽屉菜单 data-go 是否覆盖全部页面路由
修复方案：建立导航映射表，确保每个展示数据的区域点击后都跳转到对应详情页：
  • 首页 → 今日计划区域 → go("todo")
  • 首页 → 糖币统计 → go("game")
  • 首页 → 藏品统计 → go("game") + 切换藏品 tab
  • 首页 → 今日概览环 → 对应模块页
  • 洞察页 → 模块入口 → 对应模块页

用户管理页面 · 头像更换功能
优先级: 中

现状分析

当前用户管理页面 (renderUsers() 行 6708+) 中，用户头像使用 emoji 占位：👑(管理员) / 🐱(家属)。仅抽屉 (#drawerBrand) 有头像上传功能（当前用户），用户管理页面无法为各用户更换头像。

需求

  • 用户管理页面每个用户旁增加「更换头像」入口
  • 支持从本地上传图片（复用现有 avatarInput 逻辑）
  • 头像上传后存储到 Supabase 云端，跨设备同步
  • 管理员可为本组家属更换头像；用户可更换自己的头像

实现方案

// 1. 用户表新增 avatar 字段（存 Base64 或 Supabase Storage URL） ALTER TABLE app_users ADD COLUMN IF NOT EXISTS avatar_url TEXT; // 2. renderUsers() 中 gm-avatar 区域改为可点击 <div class="gm-avatar js-change-avatar" data-uid="${u.id}" data-name="${esc(u.username)}" style="cursor:pointer;position:relative"> ${u.avatar_url ? `<img src="${u.avatar_url}" style="width:100%;height:100%;object-fit:cover;border-radius:50%">` : (u.role === 'admin' ? '👑' : '🐱')} <span class="avatar-cam">📷</span> </div> // 3. 点击触发文件选择 → 上传 → 更新数据库 → 重新渲染 $(".js-change-avatar").onclick = () => { const input = document.createElement("input"); input.type = "file"; input.accept = "image/*"; input.onchange = async (e) => { const file = e.target.files[0]; const resized = await resizeImage(file, 200); // 压缩到 200px await auth.updateUserAvatar(uid, resized); // 写入云端 renderUsers(); // 重新渲染 }; input.click(); };

权限控制

  • 管理员：可更换本组所有用户头像
  • 家属：仅可更换自己头像（用户管理页面中仅自己的头像可点击）
  • 跨组用户头像不可修改

头像使用场景联动

  • 抽屉侧栏 #brandImg：显示当前用户头像
  • 用户管理页面 gm-avatar：显示各用户头像
  • 记账/计划/灵感记录的来源筛选标签：头像缩略图（可选，后续迭代）

设计参考 · Hallmark 理念融入

参考 Hallmark 的"refuses to look AI-generated"原则，避免以下 AI 生成痕迹：

拒绝居中堆叠拒绝渐变背景一刀切拒绝 emoji 滥用拒绝等宽卡片网格

具体：首页布局采用不对称构图（左大右小），问候区偏左、概览环偏右，打破对称感

设计参考 · Emil Kowalski 动画理念

页面切换：使用 ease-out 而非 ease-in（出场快→减速停下，符合自然预期）

卡片 hover：transform translateY(-2px) + 阴影增强，时长 200ms

弹窗/抽屉：使用 cubic-bezier(0.32,0.72,0,1) 替代默认 ease

列表项删除/添加：使用 max-height + opacity 过渡，而非直接 display:none

设计参考 · UI/UX Pro Max 理念

信息层级：每屏只突出 1 个主要操作（F 型视觉扫描），次要操作收进抽屉/折叠

色彩约束：主色不超过 3 种，其余用中性灰；当前 4 模块色保留但降低饱和度 10%

间距系统：统一使用 4px 倍数（4/8/12/16/24/32/48），消除随意间距

设计精修（融入三个设计技能理念）
优先级: 低

整体调性

保留布偶小猫清新奶油萌系风格，不做颠覆性改版。以下是微调项，让整体更有时尚网感、适合现代情侣使用。

4.1 字体系统优化

  • 正文：当前系统字体保留
  • 标题/数字：引入 font-weight:800 层级，数字用 font-variant-numeric:tabular-nums 等宽对齐
  • 金句区：英文用衬线体（Georgia 或 "Noto Serif SC"），中文用楷体感，增加文艺气质

4.2 色彩微调（保持配色不变，降饱和 + 提质感）

// CSS 变量微调建议 --bg: #faf7f2; // 保留 --surface: #ffffff; // 保留 --surface-card: #fffdf8; // 略微调暖 --border: #f0e6da; // 保留 --text: #3a3027; // 保留 --text-secondary: #8a7b6a; // 略降饱和 --text-tertiary: #b8a898; // 略降饱和 --accent: #d97a4a; // 保留（暖橘） --candy: #e89ab8; // 保留（粉） // 新增情侣色对 --accent-pair-1: #e8a0a0; // 浅珊瑚（猫一） --accent-pair-2: #a0c4e8; // 浅天蓝（猫二）

4.3 动效系统（Emil Kowalski 风格）

  • 页面切换：淡入 + translateY(8px) → 0，200ms ease-out
  • 卡片入场：stagger 错落，每项延迟 50ms
  • 数字变化：滚动动画（从旧值过渡到新值），而非直接跳变
  • 勾选任务：勾选框 200ms 弹性 + 文字删除线从左到右展开
  • 糖币获得：+N 文字从记录位置飘起，translateY(-30px) + opacity:1→0，800ms

4.4 情侣元素（轻量、不破坏现有风格）

  • 首页问候区右侧：小巧的"在一起 X 天"计时器（pills 形，--accent-pair-1 底色）
  • 记账本筛选标签：管理员标签用 --accent-pair-2，家属标签用 --accent-pair-1，视觉区分清晰
  • 抽屉底部：双猫剪影 SVG 装饰（极简线条，2 只猫面对面）
  • 金句区保留现有猫装饰图 (nav-yan-huo.png)，不替换

4.5 不变动清单（硬约束）

  • 底部导航 4 个图标 (assets/nav-*.png) — 不替换
  • 首页 banner 主图 (assets/banner-cats-new.jpg) — 不替换
  • 头像图 (assets/avatar.jpg) — 不替换
  • 金句背景图 (assets/quote-bg.jpg) — 不替换
  • 整体奶油浅色系配色 — 不改变
  • 软萌文案风格 — 保留（仅品牌名替换）
