定位：情侣共同记账和时间规划的移动端 Web App

最大宽度：480px（移动端优先，居中布局）

3.1 记账本（money）

分类：餐饮/饮品/交通/购物/学习/居家/娱乐/兼职/其他

字段：id, title, type(expense/income), amount, category, date, createUserId, createRole

统计：支出总额、预算、结余 — 切换筛选标签后三项动态重算

筛选标签：【全部】【管理员创建】【家属创建】

3.2 今日计划（todo）

优先级：P0(重要/红) P1(一般/金) P2(随手/绿)

字段：id, title, priority, done, time, date, note, _candySettled

3.3 习惯打卡（checkin）

结构：{ id, title, log: { "2026-08-26": true } }

连续天数衰减：断签1天 -3，断签3天归零

3.4 长期目标（goal）

字段：id, title, current, target, unit, note

进度条 = current / target × 100%

3.5 灵感备忘（note）

分类：学习笔记/市场观察/灵感速记/读书摘录/AI技术/金融知识/生活随笔/其他

心情标签：灵感/复盘/资讯/备忘

特殊布局：layout:"quote"（金句卡片）、layout:"feature"（带图特写）

四、游戏体系

4.1 糖币系统（归属分组）

存储位置：分组 key cat-time-bureau-v1-g{groupId}

产出：完成任务 +5、记账 +5（每日上限可配）

家属：可产出、不可兑换消耗

管理员：完整兑换、消耗权限

4.2 小猫等级（上限 50 级）

升级条件：累计糖币达到阈值

等级 = floor(总糖币 / 50) + 1

4.3 奖品超市

兑换消耗糖币，道具包括：成长奶糕（直升3级）、高级猫条（直升5级）

动态定价：奶糕 = 350 + 等级×50；猫条 = 900 + 等级×120

限购：奶糕最多8次，猫条最多4次，总直升上限20级

4.4 藏品图鉴

兑换奖品后入册，展示已收集的品种

4.5 每日任务

每日刷新，完成获得糖币奖励

4.6 连续记录

打卡/记账连续天数统计，Buff 加成

五、权限模型

能力管理员家属
记账本/计划/目标/灵光 读写✅✅
习惯打卡✅❌
产出糖币✅✅
兑换/消耗糖币✅❌（按钮置灰）
用户管理✅❌
头像修改本组全部仅自己

数据隔离：同组共享业务数据，跨组完全隔离。

账户上限：全局最多 4 个账号。

六、数据架构

6.1 存储 Key 设计

Key 格式用途内容
cat-time-bureau-v1-g{groupId}分组业务+游戏数据money/todo/note/checkin/goal + __candyLog/__level/__togetherDate 等
cat-time-bureau-v1-u{userId}个人游戏数据（旧，迁移用）历史糖币流水（迁移后废弃）

6.2 Supabase 表结构

workbench_data:
  id          (uuid PK)
  storage_key (text UNIQUE)
  data        (jsonb)        -- 全部业务+游戏数据
  device_id   (text)
  updated_at  (timestamptz)

users:
  id, username, password_hash, role(admin/family),
  group_id, apply_status, avatar, created_at

groups:
  id, name, invite_code, created_at

family_applications:
  id, group_id, applicant_username, status, created_at

6.3 同步策略

双写：localStorage + Supabase Cloud，云端为 source of truth

Realtime：订阅 workbench_data 表变更，同组多设备实时同步

防重复：_candySettled 标记防止糖币重复发放

九、设计风格指南

整体基调

清新奶油萌系 + 情侣双色调，拒绝商务硬核/暗黑风格。

文案软萌（"二猫觉得…喵～"），保留猫爪/猫emoji装饰。

动效原则

页面切换 200ms ease-out 淡入 + 上移

卡片 :active 缩放 0.97 即时反馈

导航活跃态：图标缩放 1.08 + 发光

概览环形 hover 缩放反馈

响应式

最大宽度 480px 居中，底部导航 fixed 定位

padding-bottom: env(safe-area-inset-bottom) 适配刘海屏

背景纹理

页面底色蓝色科技感 #e6edf5

糖果小铺渐变：橙→蓝→紫三段渐变

金句卡片：背景图 + 径向渐变遮罩

装饰猫爪 ::before/::after 透明度 0.08-0.12
